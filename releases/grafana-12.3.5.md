# Grafana v12.3.5

_Veroeffentlicht: 2026-03-09_ · [Release auf GitHub](https://github.com/grafana/grafana/releases/tag/v12.3.5)

## Breaking Changes
- Keine.

## Hilfreiche neue Funktionen
- Der Image Renderer unterstuetzt nun eigene CA-Zertifikate, was den Betrieb hinter internen TLS-Terminierungen bzw. mit eigener PKI erleichtert ([#118910](https://github.com/grafana/grafana/pull/118910)).

## Hilfreiche Informationen
- Go wurde auf Version 1.25.8 aktualisiert ([#119694](https://github.com/grafana/grafana/pull/119694)).
- Dashboards: Der `start`-Parameter der List-Versions-API funktioniert im K8s-Backend jetzt korrekt ([#119397](https://github.com/grafana/grafana/pull/119397)).
- Reines Patch-Release ohne dokumentierte What's-new-Highlights; weitere Details auf der [Download-Seite](https://grafana.com/grafana/download/12.3.5).
