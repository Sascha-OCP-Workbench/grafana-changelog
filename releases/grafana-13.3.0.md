# Grafana v13.3.0

_Veroeffentlicht: 2026-10-27_ · [Release auf GitHub](https://github.com/grafana/grafana/releases/tag/v13.3.0)

_Uebersicht: [What's new in v13.3.0](https://grafana.com/docs/grafana/latest/whatsnew/whats-new-in-v13-3/)_

> Legende: ⚠️ Doku-Anpassung noetig / potenziell breaking (von Grafana nicht als Breaking Change gekennzeichnet, kann aber Bestehendes brechen oder eine Doku-Anpassung erfordern) · 🔧 neuer Default (Verhalten ab jetzt standardmaessig aktiv/geaendert)

## Breaking Changes
- **Plugins marketplace: Rename config.ini section from marketplace to plugins_marketplace** — Der Konfigurationsabschnitt in der `config.ini` muss von `[marketplace]` auf `[plugins_marketplace]` umbenannt werden ([#132172](https://github.com/grafana/grafana/pull/132172)).
