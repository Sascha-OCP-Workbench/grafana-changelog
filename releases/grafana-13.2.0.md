# Grafana v13.2.0

_Veroeffentlicht: 2026-08-18_ · [Release auf GitHub](https://github.com/grafana/grafana/releases/tag/v13.2.0)

## Breaking Changes
- **Alerting:** Das Feature-Flag `alertingSaveStateCompressed` wurde entfernt ([#129135](https://github.com/grafana/grafana/pull/129135)).
- **Alerting:** Die Notifications-API wurde auf `v1beta1` migriert; Clients und Automatisierungen muessen auf die neue Version umgestellt werden ([#124702](https://github.com/grafana/grafana/pull/124702)).
- **Alerting:** Bei Provenance-Konflikten an Contact Points liefert die API nun HTTP 403 statt 500 – abweichende Fehlerbehandlung in Automatisierungen pruefen ([#127699](https://github.com/grafana/grafana/pull/127699)).
- **Dashboards:** Scripted Dashboards sind deprecated und standardmaessig deaktiviert; bestehende Nutzung erfordert Migration oder explizites Aktivieren ([#130207](https://github.com/grafana/grafana/pull/130207)).
- **Dashboards:** Die neuen View-Panel-Controls sind standardmaessig aktiv, Dashboard-Settings-Tabs leiten auf die Sidebar-Pendants um ([#129187](https://github.com/grafana/grafana/pull/129187), [#125966](https://github.com/grafana/grafana/pull/125966)).
- **Home:** Die Unified Homepage ist ohne Feature-Flag fuer alle Nutzer aktiv ([#129054](https://github.com/grafana/grafana/pull/129054)).
- **Provisioning:** Git Sync Conventions, User Attribution und der GitHub-Enterprise-Provider sind standardmaessig aktiviert ([#130670](https://github.com/grafana/grafana/pull/130670), [#130671](https://github.com/grafana/grafana/pull/130671), [#128376](https://github.com/grafana/grafana/pull/128376)).
- **Unified Storage:** Der Default fuer Garbage-Collection-Dry-Run steht jetzt auf `false`, d.h. es wird real geloescht ([#130533](https://github.com/grafana/grafana/pull/130533)).
- **Alerting:** Das Feature-Toggle `AlertingCentralHistory` wurde entfernt ([#130164](https://github.com/grafana/grafana/pull/130164)).

## Hilfreiche neue Funktionen
- **Alerting:** Neuer Import-Tab in den Alerting-Settings inkl. ImportToGMAWizard mit Promote/Auto-Sync, Import von Notification Templates, Zusammenfassung und Revert einer Staged Configuration ([#129051](https://github.com/grafana/grafana/pull/129051), [#126907](https://github.com/grafana/grafana/pull/126907), [#128329](https://github.com/grafana/grafana/pull/128329), [#129204](https://github.com/grafana/grafana/pull/129204), [#129243](https://github.com/grafana/grafana/pull/129243)).
- **Provisioning:** Git Sync unterstuetzt jetzt GitHub Enterprise (Server und Cloud) inkl. Webhooks und Dashboard Previews ([#127614](https://github.com/grafana/grafana/pull/127614), [#127209](https://github.com/grafana/grafana/pull/127209)).
- **Provisioning:** Webhooks fuer GitLab und Bitbucket sind verfuegbar, inkl. UI und provider-agnostischem Webhook-Lifecycle ([#127204](https://github.com/grafana/grafana/pull/127204), [#128649](https://github.com/grafana/grafana/pull/128649), [#127806](https://github.com/grafana/grafana/pull/127806)).
- **Provisioning:** Commits koennen mit Autoreninformationen versehen werden – als Signer oder mit Author-Override, sonst als angemeldeter Grafana-Benutzer ([#127970](https://github.com/grafana/grafana/pull/127970), [#130547](https://github.com/grafana/grafana/pull/130547)).
- **Provisioning:** Jobs werden Autor und Herkunft zugeordnet und in den Recent Jobs angezeigt ([#128819](https://github.com/grafana/grafana/pull/128819), [#128820](https://github.com/grafana/grafana/pull/128820), [#127984](https://github.com/grafana/grafana/pull/127984)).
- **Provisioning:** Migrate-to-GitOps mit Branch-Auswahl, Paginierung, Ordnerpfaden, Job-Fehleranzeige und Filter fuer Out-of-Sync-Ressourcen ([#128562](https://github.com/grafana/grafana/pull/128562), [#128356](https://github.com/grafana/grafana/pull/128356), [#128042](https://github.com/grafana/grafana/pull/128042), [#127936](https://github.com/grafana/grafana/pull/127936), [#128456](https://github.com/grafana/grafana/pull/128456)).
- **Provisioning:** Der Per-Resource-Write-Timeout beim Sync ist konfigurierbar, und ein vollstaendiger Pull statt inkrementellem Sync kann erzwungen werden ([#127862](https://github.com/grafana/grafana/pull/127862), [#128330](https://github.com/grafana/grafana/pull/128330)).
- **Azure Monitor:** Unterstuetzung der Azure Metrics Batch API buendelt Abfragen mehrerer Ressourcen und reduziert Throttling ([#123696](https://github.com/grafana/grafana/pull/123696)); Subscription-Lookups werden gecacht ([#123556](https://github.com/grafana/grafana/pull/123556)).
- **Tracing:** Neuer File-Exporter schreibt Traces als OTLP/JSON, ohne dass ein OpenTelemetry Collector noetig ist ([#128679](https://github.com/grafana/grafana/pull/128679), Doku: [#129339](https://github.com/grafana/grafana/pull/129339)).
- **Live:** `ha_engine_address` unterstuetzt `redis://` und `rediss://` (TLS) Verbindungs-URLs ([#129938](https://github.com/grafana/grafana/pull/129938)).
- **Plugins:** Neues Feature-Toggle zum Erzwingen von TLS 1.3 ([#130390](https://github.com/grafana/grafana/pull/130390)).
- **Dashboards:** Query-Variablen-Editor neu gestaltet, Threshold-Interpolation, Verschachtelungstiefe 4 mit nested Tabs sowie vereinheitlichte Anzeige von Panel-Query-Fehlern und -Hinweisen ([#127048](https://github.com/grafana/grafana/pull/127048), [#128451](https://github.com/grafana/grafana/pull/128451), [#129174](https://github.com/grafana/grafana/pull/129174), [#127436](https://github.com/grafana/grafana/pull/127436)).
- **View Panel:** Controls-Sidebar (Public Preview) erlaubt Anpassungen ohne Edit-Rechte inkl. Fan-out-Option mit URL-Sync ([#128270](https://github.com/grafana/grafana/pull/128270)).
- **Logs:** Mehr Suggested Fields mit Integration in die neue Logs Table, Trace-to-Logs-Button nur bei vorhandenen Logs ([#128002](https://github.com/grafana/grafana/pull/128002), [#128702](https://github.com/grafana/grafana/pull/128702)).
- **CloudWatch Logs:** Frontend-Unterstuetzung fuer Abfragen nach Data Source ([#123742](https://github.com/grafana/grafana/pull/123742)).
- **Table/DashList:** Zelltooltips mit dynamischer Hoehe und Dashboard-Beschreibung als Tooltip in DashList ([#127107](https://github.com/grafana/grafana/pull/127107), [#130006](https://github.com/grafana/grafana/pull/130006)).
- **Transformations:** Merge series/tables bleibt auch bei nur einer Datenserie verfuegbar ([#129569](https://github.com/grafana/grafana/pull/129569)).
- **Laut What's-new-Doku:** Saved Queries sind in Enterprise/Cloud generally available (Command Palette, Terraform-Provisioning), Multi-Select-Gruppierung von Panels, OpenSearch Index Browser, Oracle Easy Connect Plus sowie Workload Identity Federation fuer BigQuery und Google Cloud Monitoring (Cloud).

## Hilfreiche Informationen
- **Security:** Dieses Release enthaelt einen Fix fuer CVE-2026-17183.
- **Go:** Die Go-Version wurde auf 1.26.5 aktualisiert ([#128011](https://github.com/grafana/grafana/pull/128011)).
- **Alerting-Bugfixes:** Zeitintervalle pruefen managed Routes beim Loeschen, faelschlich angezeigtes "Inhibited" im Rule-Detail behoben, Reset der Default-Route loescht nicht mehr die Provenance aller managed Routes ([#129247](https://github.com/grafana/grafana/pull/129247), [#130264](https://github.com/grafana/grafana/pull/130264), [#130553](https://github.com/grafana/grafana/pull/130553)).
- **Auth:** Doppelte gleichzeitige Login-Pings werden dedupliziert, Session-Token-Rotation entfaellt bei nicht sessionbasierten Requests ([#129927](https://github.com/grafana/grafana/pull/129927), [#129920](https://github.com/grafana/grafana/pull/129920)).
- **Provisioning-Stabilitaet:** Zahlreiche Fixes fuer Job-Leases in Multi-Pod-Betrieb (Claim-Ownership, Lease-Erneuerung, Abbruch bei Lease-Verlust, NotFound-Toleranz beim Cleanup) ([#127783](https://github.com/grafana/grafana/pull/127783), [#127786](https://github.com/grafana/grafana/pull/127786), [#127792](https://github.com/grafana/grafana/pull/127792), [#127753](https://github.com/grafana/grafana/pull/127753)).
- **Provisioning:** GitHub-Webhook-Erstellung ist idempotent, sodass Repos nicht mehr mit HTTP 422 unhealthy bleiben ([#128068](https://github.com/grafana/grafana/pull/128068)); v0-Dashboards werden als v1 exportiert ([#128357](https://github.com/grafana/grafana/pull/128357)).
- **PostgreSQL:** Data-Source-Init mit `maxOpenConns=0` schlaegt nicht mehr fehl, Epoch-ms-Strings werden korrekt geparst ([#122556](https://github.com/grafana/grafana/pull/122556), [#122693](https://github.com/grafana/grafana/pull/122693)).
- **SQLite:** Der Journal-Mode wird zurueckgesetzt, wenn WAL deaktiviert ist ([#130695](https://github.com/grafana/grafana/pull/130695)).
- **Azure Monitor:** Migration der Dimension-Filter korrigiert ([#128786](https://github.com/grafana/grafana/pull/128786)).
- **Logs Table:** Fixes fuer Datenexport, fehlende Ergebnisse beim Streaming, Feld-/Anzeigenamen-Mix und haengende Filter ([#130245](https://github.com/grafana/grafana/pull/130245), [#128870](https://github.com/grafana/grafana/pull/128870), [#128677](https://github.com/grafana/grafana/pull/128677), [#128398](https://github.com/grafana/grafana/pull/128398)).
- **Transformations:** Fixes fuer Filter-by-value mit Regex und null-Werten, Gazetteer-Lookups, Feldnamen-Deduplizierung in Extract fields und Inner Join bei entfallenen Frames ([#129572](https://github.com/grafana/grafana/pull/129572), [#129568](https://github.com/grafana/grafana/pull/129568), [#129889](https://github.com/grafana/grafana/pull/129889), [#129576](https://github.com/grafana/grafana/pull/129576)).
- **Navigation/UI:** orgId wird in alle Navigationen injiziert, ausgewaehlte Datenquelle wird im Picker wieder hervorgehoben, Panel-Header-Abstaende korrigiert ([#120978](https://github.com/grafana/grafana/pull/120978), [#126948](https://github.com/grafana/grafana/pull/126948), [#128910](https://github.com/grafana/grafana/pull/128910)).
- **Accessibility:** InlineToast wird von Screenreadern angesagt, Section-Headings auf Variablen-Seiten korrekt ausgezeichnet, `aria-current` auf aktiver Seite in Pagination ([#128488](https://github.com/grafana/grafana/pull/128488), [#130706](https://github.com/grafana/grafana/pull/130706), [#128494](https://github.com/grafana/grafana/pull/128494)).
