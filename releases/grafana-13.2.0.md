# Grafana v13.2.0

_Veroeffentlicht: 2026-08-18_ · [Release auf GitHub](https://github.com/grafana/grafana/releases/tag/v13.2.0)

_Uebersicht: [What's new in v13.2.0](https://grafana.com/docs/grafana/latest/whatsnew/whats-new-in-v13-2/)_

> Legende: ⚠️ potenziell breaking (von Grafana nicht als Breaking Change gekennzeichnet, kann aber Bestehendes brechen) · 🔧 neuer Default (Verhalten ab jetzt standardmaessig aktiv/geaendert)

## Breaking Changes
- **Alerting:** Das Feature-Flag `alertingSaveStateCompressed` wurde entfernt [#129135](https://github.com/grafana/grafana/pull/129135).
